## 📋 Actions Obligatoires Après Déploiement

### 1. Configuration DNS (propulsion.cm)
```
Type A : @ → IP du serveur
Type CNAME : www → propulsion.cm
Type MX : @ → serveur email
```

### 2. Configuration Email (contact@propulsion.cm)
- Configurer le serveur email
- Tester la réception
- Mettre à jour dans le footer si différent de info@claudel-noubissie.com

### 3. Google Search Console
1. Aller sur https://search.google.com/search-console
2. Ajouter la propriété propulsion.cm
3. Vérifier avec balise HTML (déjà préparée dans le code)
4. Soumettre le sitemap : https://propulsion.cm/sitemap.xml
5. Demander l'indexation

### 4. Vérification URL Facebook
- Valider l'URL exacte de la page Facebook
- Mettre à jour dans le code si nécessaire
- Ajouter dans les liens du footer

### 5. SSL/HTTPS
- S'assurer que le certificat SSL est actif
- Toutes les URLs doivent être en HTTPS
