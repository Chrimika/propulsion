## 📋 Actions Post-Déploiement

### 1. **Google Search Console**
```
1. Accédez à https://search.google.com/search-console
2. Ajoutez la propriété propulsion.cm
3. Vérifiez la propriété (méthode balise HTML déjà préparée dans layout.tsx)
4. Soumettez le sitemap : https://propulsion.cm/sitemap.xml
5. Demandez l'indexation de la page principale
```

### 2. **Google Analytics (optionnel)**
```
1. Créez un compte GA4
2. Obtenez l'ID de mesure (G-XXXXXXXXXX)
3. Ajoutez le script dans layout.tsx
```

### 3. **Google My Business**
```
1. Créez un profil d'entreprise Google
2. Catégorie : Organisation communautaire / Service professionnel
3. Ajoutez les coordonnées et photos
4. Localisations : Yaoundé, Douala
```

### 4. **Bing Webmaster Tools**
```
1. Accédez à https://www.bing.com/webmasters
2. Ajoutez le site propulsion.cm
3. Soumettez le sitemap
```

### 5. **Vérification du Référencement**
Après déploiement, vérifiez :
- [ ] `site:propulsion.cm` sur Google
- [ ] Rich snippets avec l'outil de test Google
- [ ] Performance mobile (PageSpeed Insights)
